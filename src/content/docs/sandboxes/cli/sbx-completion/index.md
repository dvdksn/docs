## Description

Generate the autocompletion script for sbx for the specified shell.
See each sub-command's help for details on how to use the generated script.


## Commands

| Command | Description |
|---------|-------------|
| [`sbx completion bash`](/sandboxes/cli/sbx-completion-bash/) | Generate the autocompletion script for bash |
| [`sbx completion fish`](/sandboxes/cli/sbx-completion-fish/) | Generate the autocompletion script for fish |
| [`sbx completion powershell`](/sandboxes/cli/sbx-completion-powershell/) | Generate the autocompletion script for powershell |
| [`sbx completion zsh`](/sandboxes/cli/sbx-completion-zsh/) | Generate the autocompletion script for zsh |

## Global Options

| Option | Default | Description |
|--------|---------|-------------|
| `-D`, `--debug` |  | Enable debug logging |
