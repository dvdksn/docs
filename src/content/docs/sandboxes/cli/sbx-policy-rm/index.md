## Synopsis

```
sbx policy rm COMMAND
```

## Description

Remove a previously added allow or deny policy.

## Commands

| Command | Description |
|---------|-------------|
| [`sbx policy rm network`](/sandboxes/cli/sbx-policy-rm-network/) | Remove a network policy |

## Global Options

| Option | Default | Description |
|--------|---------|-------------|
| `-D`, `--debug` |  | Enable debug logging |
