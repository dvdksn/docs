New to Docker? This guide takes you from zero to running your first
multi-container application in four steps.

1. [**Overview**](/get-started/overview/) — What Docker is, how it works, and
   why developers use it.
2. [**Install Docker**](/get-started/install/) — Get Docker Desktop and run your
   first container.
3. [**Build your first app**](/get-started/build-your-first-app/) — Write a
   Dockerfile, build an image, add a database with Compose, and push to Docker
   Hub.
4. [**Next steps**](/get-started/next-steps/) — Where to go from here: guides,
   optimization, and production patterns.

Each step builds on the previous one. By the end, you'll understand images,
containers, volumes, networking, and Docker Compose — the core building blocks
for any Docker workflow.
