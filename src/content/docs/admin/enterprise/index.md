Enterprise administration covers deploying Docker Desktop at scale, enforcing
security and compliance policies, and diagnosing issues that affect managed
environments.

## In this section

- [Enterprise deployment](/admin/enterprise/enterprise-deployment/) — install and configure Docker Desktop on Windows and macOS fleets using MSI, PKG, Intune, Jamf Pro, and the Microsoft Store
- [Enterprise security](/admin/enterprise/security/) — single sign-on, SCIM provisioning, domain management, enforce sign-in, roles and permissions, and Hardened Docker Desktop
- [Troubleshoot provisioning](/admin/enterprise/troubleshoot/troubleshoot-provisioning/) and [troubleshoot SSO](/admin/enterprise/troubleshoot/troubleshoot-sso/) — diagnose enterprise deployment issues
