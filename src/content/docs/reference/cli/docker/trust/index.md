## Description

Manage trust on Docker images

## Subcommands

| Command | Description |
|---------|-------------|
| [`docker trust inspect`](/reference/cli/docker/trust/inspect/) | Return low-level information about keys and signatures |
| [`docker trust key`](/reference/cli/docker/trust/key/) | Manage keys for signing Docker images |
| [`docker trust revoke`](/reference/cli/docker/trust/revoke/) | Remove trust for an image |
| [`docker trust sign`](/reference/cli/docker/trust/sign/) | Sign an image |
| [`docker trust signer`](/reference/cli/docker/trust/signer/) | Manage entities who can sign Docker images |
