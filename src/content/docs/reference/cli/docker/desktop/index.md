## Description

Control Docker Desktop from the CLI

## Subcommands

| Command | Description |
|---------|-------------|
| [`docker desktop start`](/reference/cli/docker/desktop/start/) | Start Docker Desktop |
| [`docker desktop stop`](/reference/cli/docker/desktop/stop/) | Stop Docker Desktop |
| [`docker desktop restart`](/reference/cli/docker/desktop/restart/) | Restart Docker Desktop |
| [`docker desktop status`](/reference/cli/docker/desktop/status/) | Display Docker Desktop's status |
| [`docker desktop engine`](/reference/cli/docker/desktop/engine/) | Commands to list and switch containers (Windows only) |
| [`docker desktop update`](/reference/cli/docker/desktop/update/) | Manage Docker Desktop updates |
| [`docker desktop logs`](/reference/cli/docker/desktop/logs/) | Print log entries for Docker Desktop |
| [`docker desktop disable`](/reference/cli/docker/desktop/disable/) | Disable a feature |
| [`docker desktop enable`](/reference/cli/docker/desktop/enable/) | Enable a feature |
| [`docker desktop version`](/reference/cli/docker/desktop/version/) | Show the Docker Desktop CLI plugin version information |
