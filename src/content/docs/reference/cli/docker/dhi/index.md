## Description

command-line interface for administering Docker Hardened Images.
It provides commands to browse the DHI catalog, mirror images into your organisations and manage customizations.

## Subcommands

| Command | Description |
|---------|-------------|
| [`docker dhi auth`](/reference/cli/docker/dhi/auth/) | Authenticate with Docker Hub |
| [`docker dhi catalog`](/reference/cli/docker/dhi/catalog/) | Browse the Docker Hardened Images catalog |
| [`docker dhi customization`](/reference/cli/docker/dhi/customization/) | Manage Docker Hardened Images customizations |
| [`docker dhi mirror`](/reference/cli/docker/dhi/mirror/) | Mirror Docker Hardened Images to your organization |
