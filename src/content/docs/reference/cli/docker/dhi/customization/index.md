## Description

Commands to list, create, edit, and delete Docker Hardened Images customizations


## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--org` |  | Docker Hub organization (overrides config) |

## Subcommands

| Command | Description |
|---------|-------------|
| [`docker dhi customization build`](/reference/cli/docker/dhi/customization/build/) | Manage customization builds |
| [`docker dhi customization create`](/reference/cli/docker/dhi/customization/create/) | Create a new customization from YAML file |
| [`docker dhi customization delete`](/reference/cli/docker/dhi/customization/delete/) | Delete a customization |
| [`docker dhi customization edit`](/reference/cli/docker/dhi/customization/edit/) | Edit an existing customization from YAML file |
| [`docker dhi customization get`](/reference/cli/docker/dhi/customization/get/) | Get details of a specific customization |
| [`docker dhi customization list`](/reference/cli/docker/dhi/customization/list/) | List all customizations |
| [`docker dhi customization prepare`](/reference/cli/docker/dhi/customization/prepare/) | Prepare a new customization YAML file from a DHI base image tag |
