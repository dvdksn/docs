## Description

Commands to browse available Docker Hardened Images and Helm charts

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--org` |  | Docker Hub organization (overrides config) |

## Subcommands

| Command | Description |
|---------|-------------|
| [`docker dhi catalog get`](/reference/cli/docker/dhi/catalog/get/) | Get details of a Docker Hardened Image |
| [`docker dhi catalog list`](/reference/cli/docker/dhi/catalog/list/) | List available Docker Hardened Images |
