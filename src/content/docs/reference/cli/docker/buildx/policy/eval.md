## Description

Evaluate policy for a source

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--fields` |  | Fields to evaluate |
| `-f`, `--file` | `Dockerfile` | Policy filename to evaluate |
| `--platform` |  | Target platform for policy evaluation |
| `--print` |  | Print policy output |
