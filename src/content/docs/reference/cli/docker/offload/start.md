## Options

| Option | Default | Description |
|--------|---------|-------------|
| `-a`, `--account` |  | The Docker account to use |
| `-g`, `--gpu` |  | Request an engine with a gpu |
| `--idle-timeout` |  | How long before the engine idles |
| `--timeout` | `10s` | How long to wait for the engine to be ready |
