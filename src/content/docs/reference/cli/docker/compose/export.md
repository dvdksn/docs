## Description

Export a service container's filesystem as a tar archive

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--index` |  | index of the container if service has multiple replicas. |
| `-o`, `--output` |  | Write to a file, instead of STDOUT |
