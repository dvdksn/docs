## Synopsis

```
sbx ls [flags]
```

## Description

List all sandboxes with their agent, status, published ports, and workspace.


## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--json` |  | Output in JSON format |
| `-q`, `--quiet` |  | Only display sandbox names |

## Global Options

| Option | Default | Description |
|--------|---------|-------------|
| `-D`, `--debug` |  | Enable debug logging |
