Reference documentation for the Docker platform. See also the
[Glossary](/reference/glossary/) for terms used across products.

## Command-line

- [`docker`](/reference/cli/docker/) — the unified command-line interface,
  including subcommands shipped by Buildx, Compose, Scout, Desktop, Model
  Runner, and DHI.
- [`dockerd`](/engine/cli/dockerd/) — the Docker Engine daemon.
- [`sbx`](/sandboxes/cli/sbx/) — the Docker Sandboxes CLI.

## File formats

- [Dockerfile](/build/dockerfile/) — instructions for building container
  images.
- [Compose file](/compose/compose-file/) — declarative spec for
  multi-container applications.

## APIs & SDKs

- [Engine API](/engine/api/) — HTTP API for the Docker daemon.
- [Engine SDK](/engine/api/sdk/) — Go and Python client libraries for the
  Engine API.
- [Hub API](/hub/api/) — HTTP API for Docker Hub.
- [DVP API](/hub/api/dvp/) — Docker Verified Publisher API.
- [Extensions SDK](/desktop/extensions/extensions-sdk/api/) — API for
  building Docker Desktop extensions.
